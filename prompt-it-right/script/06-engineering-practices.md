# Block 2, part 5: Engineering practices - be ready to act fast (10 min, 12:05 - 12:15)

Tests reduce failures, these practices reduce the damage when one gets through.

| Min | Beat | Content |
|---|---|---|
| 1 | Divider | Mistakes will happen. Be ready to act fast |
| 3 | Lifecycle drawing | Shift left, CI, CD, feature flags, then monitoring, alerting, runbooks, fast rollback. Lessons go back into shift left (a new test, a new rule in the skill) |
| 2 | Shift left | Tests in the agent loop, small atomic changes, ArchUnit rules, review pass on agent tests |
| 2 | Ship safely | Fast pipeline, small releases, feature flags decouple deploy from release, progressive rollout |
| 2 | Act fast | Monitoring on user impact, alerting with an owner, runbooks, fast rollback or flag switch, fix forward |

Closing statement: you will ship a bug, how fast you recover is what counts (links back to DORA time to restore).
